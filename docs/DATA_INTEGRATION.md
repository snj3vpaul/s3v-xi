# CricHeroes integration boundaries

No CricHeroes integration is implemented and no permission for scraping is assumed. Do not reverse engineer undocumented endpoints or bypass authentication.

Future data sources, in priority order: official/authorized integration if available, authenticated administrator-imported CSV or JSON match scorecards, and manual admin entry with an audit trail. Keep stable internal IDs, validate imports, deduplicate results, record source URLs for attribution, and support corrected scorecards and deterministic recalculation. Label demo/imported/verified/stale statuses accurately.
