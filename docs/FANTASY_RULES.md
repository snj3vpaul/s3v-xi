# Proposed fantasy rules

No money, player budgets, bidding, gambling or paid cards.

Pick 15 eligible players: 2 WK, 5 BAT, 3 AR, 5 BOWL. Choose 11 starters and four reserves, with a captain and distinct vice-captain drawn from the XI. Captain scores 2× base points, vice-captain 1.5×. The bench earns zero unless Full Squad is activated, when all four reserves also earn base points. Skipper x3 replaces the captain's usual 2× multiplier with 3×. Only one chip may be used per round; allow one of each chip per tournament in production. Rebuild (permanent unlimited transfers) and One-Round XI (temporary transfers) are later features.

Suggested future base point rules: +1 per run, +1 extra for a four, +2 extra for a six, +25 per credited wicket (excluding run-outs), +12 for maiden, +8 catch, +12 stumping, +12 direct run-out, +6 assisted run-out, mutually exclusive 30/50/100 run milestones (+4/+8/+16), and -2 for an eligible duck. Treat all of these as configurable proposals, not currently implemented source scoring.

Automatic substitutions, real participation, multi-match rounds, late score corrections, cancelled games and captain absence require documented logic and tests before use with real scores.
